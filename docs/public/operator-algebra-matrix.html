The Operator Algebra — Root × Boundary

Every root in src/roots.ts is a partial function from a boundary value to an official RxJS operator. Roots run down the Y-axis, the seven-member boundary vocabulary runs across the X-axis; each plaque is a generator, each card is where the two meet. Hatched cards are combinations the type system rejects at compile time, not gaps in the docs.

companion grid · src/kept.ts

The Flattening Family — Map / All / Scan × Strategy

Concurrency strategy is a second, closed vocabulary — orthogonal to the boundary grammar above, not an eighth column on it. A boundary is a tag a root switches on in one dispatch call; a strategy only means something once you already have a higher-order stream, so it combines with map (map(project) → xAll(), the flattening law) or drives a bare flatten/scan directly — it never dispatches through take, buffer, or any root above. These ten names are the sacred core of the vocabulary: nothing here is renamed.
